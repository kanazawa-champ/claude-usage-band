# Claude の使用量の帯（usage-band）

Claude Code のデスクトップアプリで、**入力欄のすぐ上に Claude の使用量を表示する**プラグインです。

```
Claude 使用量　5時間 10%（12:10に回復）｜1週間 13%（11/13(金) 11:00に回復）
```

- **5時間の枠**と**1週間の枠**を、どれだけ使ったか（%）と、いつ回復するかで表示します
- 回復が今日なら時刻だけ、別の日なら「日付(曜日) 時刻」で表示します（日本時間）
- **80%を超えると**数字が目立つ色・太字になり、**通知**が出ます。95%でもう一度通知します。枠が回復したら、また次の80%でお知らせします
- 数字は、Claude が最後に返事をした時点のものです。まだ数字がないときは「次の返事のあとに表示します」と出ます

## 使える人

- Claude の**有料プラン（Pro・Max など）**で、**Claude Code のデスクトップアプリ**を使っている方
- API の鍵で使っている方には、使用量の数字が出ません

## 入れ方

### デスクトップアプリから（おすすめ）

1. 入力欄の左にある **「＋」** を押す
2. **「Plugins（プラグイン）」** を押す
3. **「Add marketplace（マーケットプレイスを追加）」** に次の言葉を入れて追加する

   ```
   kanazawa-champ/claude-usage-band
   ```

4. 一覧に出てくる **「usage-band」** を選んで **「Add plugin（追加）」** を押す
5. アプリを一度閉じて、開き直す

入力欄の上に「Claude 使用量」の帯が出れば完成です。

### ターミナルから

```
/plugin install usage-band --marketplace kanazawa-champ/claude-usage-band
```

「Add marketplace?」と聞かれたら `y`、入れる範囲は一番上（user）を選んでください。

## 外し方

デスクトップアプリの「＋」→「Plugins」で usage-band を外すか、ターミナルで次を実行します。

```
/plugin uninstall usage-band
```

## ご注意

- このプラグインは、Claude Code の**試験提供中（早期アクセス）の仕組み**を使っています。アプリの更新によって表示が変わったり、動かなくなったりすることがあります
- 表示される数字は Claude Code が受け取った値をそのまま出しているもので、Anthropic の公式の表示ではありません。正確な使用量は claude.ai の「設定 → 使用量」でご確認ください
